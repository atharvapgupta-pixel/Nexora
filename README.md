# Nexora

Nexora is a student collaboration platform designed to help students discover project ideas, find teammates with complementary skills, and turn ideas into meaningful projects.

## Tech Stack
* **Frontend:** Next.js (App Router), React, Tailwind CSS, Lucide Icons
* **Backend / Database:** Supabase (PostgreSQL)
* **Authentication:** Supabase Auth (Email OTP via Custom SMTP)
